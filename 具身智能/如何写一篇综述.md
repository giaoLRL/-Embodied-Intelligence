# 如何写一篇综述
## 什么是综述？
**综述 = 文献综述**，是对**某一细分研究领域**近年已有成果的**系统性总结、梳理、对比、评述**，不是简单摘抄论文，核心是**归纳、整合、评价、展望**。

1.核心定位：**看懂整个领域**，而非单篇论文；

2.内容核心：别人做了什么、怎么做的、优缺点、还缺什么；

3.区别于论文：
- 实验论文：自己提方法、做实验、出结果；
- 综述：整合别人工作，梳理发展脉络 + 横向对比 + 指出未来方向。

## 综述中哪些是论述别人，那些要自己的想法？
**纯论述别人**：客观复述前人工作，只做「整合、归类、转述」，不带主观评价。

**必须有自己想法**：分类逻辑、横向对比、优劣点评、问题总结、未来展望、全文串联逻辑。

## 如何总结一篇综述？
#### 1. 梳理范围 + 研究背景（客观复述）
这篇综述围绕**XX 细分领域**展开，梳理了该领域近 X 年的发展背景、研究意义与应用场景，明确了行业普遍存在的核心难题。
#### 2. 核心分类体系（最关键，复述它的框架）
文章按照XX **划分标准**（时间 / 技术原理 / 网络结构 / 供电方式 / 算法类别），将现有方法划分为**几大主流分支**，并逐一介绍各类方案的技术原理与发展脉络。
#### 3. 横向对比 + 现有结论（客观复述）
文中通过表格、指标对比、性能分析，横向比较了不同技术路线的优劣、适用场景与性能差异，归纳了当前主流技术的整体研究现状。
#### 4. 不足 + 挑战 + 未来方向（一半复述 + 一半理解）
该综述指出了本领域目前的共性瓶颈、落地难题，同时总结了现阶段研究局限，并预判了未来重点研究趋势与改进方向。
