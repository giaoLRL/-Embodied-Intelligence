# 碎片知识总结

## 什么是虚拟环境VENV？
虚拟环境是一个单独的隔间，为了保证纯粹和有序，有独立的第三方库和独立的Python解释器。

#### 为什么有时候有两个文件夹？
那是因为创建的命令是两个：python -m venv venv,实际上两个文件夹作用和功能一模一样没有区别。

### 1.深度学习库版本要求极度严格

torch、torchvision、torchaudio 版本必须一一对应，差一个小版本都跑不动

虚拟环境单独装一套专属版本，绝不和别的项目冲突

### 2.GPU 环境最怕乱
你 4060Ti 显卡搭配 CUDA、GPU 版 PyTorch

全局环境库一多，极易出现：明明有独显，代码识别不到 GPU

项目干净纯粹

smolvla_test项目里，虚拟环境只装：

torch、lerobot、transformers 这些刚需库

没用的库一个都不装，运行更快、报错更少

### 3.用完即弃，一键清空

这个项目不学了？直接删掉 .venv 整个文件夹
电脑原本环境毫发无伤，干干净净

## 不同库的作用
### 1.torch (PyTorch)
深度学习最核心的框架，所有ai的底层操作系统，没有它，别的库都跑不了。
- 管理所有数字计算（张量计算）
- 调用RTX4060ti显卡，让GPU加速运算
- 运行模型、生成机器人动作

### 2. torchvision
PyTorch 官方视觉处理库，专门处理图片的工具，和torch完美配套
- 处理机器人的头顶摄像头、手腕摄像头的图片
- 把图片转成模型能看懂的数字特征

比喻：汽车的视觉传感器 / 摄像头驱动，专门负责 “看东西”。

### 3. torchaudio —— 专门管「音频」的工具包
官方定位：PyTorch 官方音频处理库

专门处理声音的工具，同样配套 torch。

### 4. transformers —— 专门管「文字 / 语言」的神器
官方定位：HuggingFace 开源的大语言模型工具库，能听懂人话、处理文字的最强工具。
- 把你的指令 Pick up the red cube（拿起红色方块）
- 转换成模型能理解的语言特征
- 是 SmolVLA 模型 **「文本理解」部分的核心 **

比喻：汽车的语音助手，能听懂你说的话。

### 5. lerobot —— 专门做「机器人 AI」的专属框架

官方定位：HuggingFace 推出的机器人学习框架，你的项目本体！ SmolVLA 模型就藏在这里面。
- 提供 SmolVLAPolicy 机器人核心模型
- 封装好机器人数据集、推理、训练逻辑
- 把图像 + 语言 + 机器人动作整合到一起

比喻：汽车的整车控制系统，专门控制机器人动起来。

### 6. Conda 是干什么的？
Conda 是专门给深度学习 / 服务器设计的「全能包管理器 + 环境创建工具」

本地用的是：pip（装库）+ venv（建环境）两个工具

Conda = 一个工具顶俩，而且能管Python、CUDA、GPU 底层库、C++ 依赖，是服务器训练模型的标配。

为什么训练 SmolVLA 必须用它？

自动装GPU 版 PyTorch、CUDA（不用你手动配显卡环境，一键搞定）

能解决服务器上各种库的版本冲突（比 pip 稳定太多）

管理多版本 Python、多模型环境（比如一个环境训 SmolVLA，一个训别的模型）

本地 pip+venv = 家用小工具箱

服务器 Conda = 工业级万能工具箱（训 AI 模型必须用它）

### 7. 创建 SmolVLA Conda 环境 是干什么的？
这就是服务器版本的 .venv！功能完全一样！

本地创建 .venv → 给 SmolVLA 单独一个隔离环境

服务器用 Conda 创建 smolvla 环境 → 给服务器训练 SmolVLA 单独一个隔离环境

####核心作用

只在这个环境里装SmolVLA 训练需要的库（torch、lerobot、transformers）

和服务器上其他项目完全隔离，不打架、不报错

保证 GPU 训练环境纯净、稳定

### 4. tmux 是干什么的？（服务器训练必用！）

tmux 是服务器远程终端的「后台保活神器」

解决一个致命问题：

你本地电脑关了、断网了、关掉终端了 → 服务器上的训练直接中断，白练了

tmux 到底干了啥？

它会在服务器上创建一个独立的后台窗口

把 SmolVLA 训练命令丢进 tmux 里运行

就算你本地关机、断网、退出远程连接

服务器上的训练还在继续跑！

下次重新连服务器，能一键切回训练窗口，看进度
