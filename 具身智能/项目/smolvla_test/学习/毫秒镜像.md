# 毫秒镜像使用指南
现在官网个人中心界面，复制专属URL

在docker Desktop中修改docker Engine,在大括号内添加 registry-mirrors 字段：

```json
{
  "builder": {
    "gc": {
      "defaultKeepStorage": "20GB",
      "enabled": true
    }
  },
  "experimental": false,
  "registry-mirrors": [
    "https://[你的专属ID].1ms.run",
    "https://docker.1ms.run"
  ]
}
```

#### linux系统
用以下指令：
```bash
# 1. 创建配置目录（如果不存在）
sudo mkdir -p /etc/docker

# 2. 写入配置文件（自动覆盖原有内容）
sudo tee /etc/docker/daemon.json >/dev/null <<'EOF'
{
  "registry-mirrors": [
    "https://[你的专属ID].1ms.run",
    "https://docker.1ms.run"
  ]
}
EOF

# 3. 重新加载配置并重启 Docker
sudo systemctl daemon-reload
sudo systemctl restart docker
```
## 与代理的关键差异

普通的代理只是简单转发，无缓存，和协议无关。

而毫米镜像的代理能够做到加速和缓存，会将用户下载过的公共资源进行缓存，再有用户同样的资源时就可以直接从国内服务器下载。

最重要的原因还是毫米镜像有协议优化，能够并发下载多个镜像层，还能够断点续传，直接用代理下载，网络不稳定就断掉了，就得从头来，尤其是比较大的文件，根本下载不了。
