# 具身智能面临的问题
1.操作能力问题，在受控环境下，可以完成特定任务，但远未达到通用、稳定、可部署的水平。只能做短时序任务，缺乏世界模型导致现实世界接触建模困难，没有物理直觉
# 世界模型
世界模型是一个对环境动态的内部表示，用于刻画状态转移与奖励生成过程，从而支持预测、规划与决策。（只预测结果，不能发送行动指令）
世界模型现在基本分为三大类：显式动力学模型，潜变量世界模型（主流），视频生成/transformer世界模型（新趋势）
## 显示动力学模型
把系统的物理演化写成一个可计算函数，然后在控制/预测中反复调用，相当于规划算法，寻找最优解。
## 潜变量世界模型
在压缩后低维空间中里学习环境的动力学，并在这个空间里做预测与规划
主流框架：encoder(CNN / Transformer)->Dynamics model（RNN / MLP）->decoder（反卷积，transformer decoder）
> CNN:提取局部空间特征，Transformer:提取全局空间特征，RNN：预测建模时间序列，MLP：预测静态空间
encoder通过深度学习加上时间和动作约束丢弃无关数据
Dynamics model模拟未来做强化学习，预测未来状态。
decoder通过深度学习将潜变量空间映射回真实空间，并生成预测结果。（可以不需要，直接在低维空间做决定）
## 视频生成/transformer世界模型
用序列模型（通常是 Transformer）直接学习“观测+动作”的时间演化，并生成未来轨迹(本质转化为序列生成问题)
Latent Token + Transformer + Diffusion（或自回归） 的统一序列建模框架
Latent Tokenization（必须）
图像 → latent token（VQ-VAE / VAE / tokenizer）
降维 + 离散化（便于Transformer处理）

Transformer 主体（核心）
时空统一建模（space + time）
输入：
(z₁, a₁, z₂, a₂, ...)
学：
下一步 latent / token

生成方式（两大路线）
Diffusion（当前最强画质）,Autoregressive（更接近控制）

能做到高质量短期世界模型预测，但无法做长时世界模型预测。
